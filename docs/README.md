# Reference Books

This directory contains condensed reference guides used by the project's AI agents to maintain code quality standards.

## Sources

All reference books are sourced from [agent-rules-books](https://github.com/ciembor/agent-rules-books/) by ciembor. These are condensed ("mini") versions of well-known software engineering books, reformatted as structured instruction sets for AI-assisted development.

### Books

| File | Original Book | Author |
|------|--------------|--------|
| `clean-code.mini.md` | *Clean Code* | Robert C. Martin |
| `clean-architecture.mini.md` | *Clean Architecture* | Robert C. Martin |
| `refactoring.mini.md` | *Refactoring* | Martin Fowler |
| `patterns-of-enterprise-application-architecture.mini.md` | *Patterns of Enterprise Application Architecture* | Martin Fowler |
| `domain-driven-design-distilled.mini.md` | *Domain-Driven Design Distilled* | Vaughn Vernon |
| `release-it.mini.md` | *Release It!* | Michael T. Nygard |

## Usage

Each agent role is assigned specific reference books in `AGENTS.md`. The agents consult these guides when planning, implementing, reviewing, or auditing code changes to ensure consistency with established software engineering principles.
